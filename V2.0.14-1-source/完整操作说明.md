# 测试能力成熟度 V2.0.14-1 操作说明

适用环境：Windows，已安装 CPython 3.10–3.13，并勾选 Add Python to PATH。本包为完整可运行服务版，需启动服务（不是双击 HTML）。

## 1. 解压与目录

请解压/复制到独立目录，例如 `E:\raft\V2.0.14-1\`。  
**不要覆盖、不要改动** 已有的 `E:\raft\V2.0.14\`。V2.0.14 是回滚基线。

## 2. 首次启动

1. 进入 `V2.0.14-1` 目录。
2. 双击 `start.bat`。首次会创建隔离环境，并从包内 `packages` 离线安装依赖，不需要上网。
3. 启动失败时窗口会保持打开，同目录生成 `startup.log`，把日志发给维护人员即可。

## 3. 日常启动与访问

- 日常启动：双击 `start.bat`，保持窗口开启。
- 本机访问：<http://127.0.0.1:5000>
- 局域网访问：使用启动窗口显示的 LAN URL。
- 健康检查：<http://127.0.0.1:5000/api/health> 应返回 `"version": "V2.0.14-1"`。

## 4. 登录

打开首页可访客只读浏览。进入「能力成熟度达成情况」「本月未达成记录」「组织关系配置」时需要登录。

初始密码：
- 管理员：`admin` / `123qweasd`
- 能力Owner 角色密码：`owner123`
- 业务角色密码：`biz123`

请管理员登录后尽快修改。

## 5. 本月未达成项达成情况编辑（本版新增）

1. 登录后任选其一进入：左侧「本月未达成编辑」，或「能力成熟度达成情况」页右上角「本月未达成编辑」。
2. 选择自然月。系统按「计划月份（优先）或预计交付日」提取该月未达成项。
3. 可用领域、评估维度、部门、科组四个筛选，选项会随月份和其他条件联动收敛。
4. 「达成情况」列可把该项改为 `1 · 已达成` 或保持 `0 · 未达成`，保存后写入与达成情况主表相同的业务库字段；改为已达成的项保存后会离开本月未达成列表。
5. 右侧文字记录仍可填写原因/进展/下一步，一并保存。
6. 点「保存达成与记录」。刷新后达成与文字都还在。V2.0.14 其余页面与公式不变。

## 6. 数据备份与恢复

- 数据库：`data/maturity.db`（含能力数据、组织关系、修改记录、本月未达成文字记录）。
- 备份：先停止服务，再复制 `data/maturity.db`，注明日期。
- 恢复：先停止服务，保留当前库备份，再用备份文件替换 `data/maturity.db`，然后重新启动。

## 7. 停止服务

在启动窗口按 Ctrl+C，然后关闭窗口。

## 8. 回滚到 V2.0.14

不要删除或改 V2.0.14 目录。若 V2.0.14-1 有问题，直接启动原来的 `E:\raft\V2.0.14\start.bat`。

## 9. 失败时提供什么

把 `startup.log`、浏览器报错原文、以及 `/api/health` 返回内容发给维护人员。
