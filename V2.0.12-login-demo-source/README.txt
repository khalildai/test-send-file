测试能力成熟度看板 V2.0.12d（登录交互临时 demo）

基于 V2.0.12 正式版，仅调整登录交互，其余功能与 V2.0.12 完全一致。

──────────────────────────────
本 demo 验证的变更
──────────────────────────────
1. 打开即看：浏览器打开 http://127.0.0.1:5000 直接进入看板（访客只读），不再强制登录；
   总览、分布对比、能力明细、现状分析、字典、修改记录、版本记录均可直接浏览。
2. 按需登录：点击「能力成熟度达成情况」或「组织关系配置」时才弹出登录框；
   也可以随时点左上角用户区的「登录」按钮主动登录。登录框可取消（继续只读浏览）。
3. 登录方式（无个人账号）：
   - 管理员：用户名 + 密码；
   - 能力Owner / 业务：选择角色 + 输入该角色对应密码（共享密码，无用户名）。
4. 登录页不再显示任何默认密码提示。

──────────────────────────────
初始密码（请管理员尽快修改）
──────────────────────────────
  管理员：admin / 123qweasd
  能力Owner 角色密码：owner123
  业务 角色密码：biz123
修改入口：管理员登录后，左上角 →「角色密码管理」→ 对应角色「修改密码」。

──────────────────────────────
角色权限（与 V2.0.12 一致）
──────────────────────────────
  管理员：全部权限（含角色密码管理、所有编辑）；
  能力Owner：仅可编辑能力项属性（达成/预期列只读）；
  业务：仅可修改达成情况与 9月/12月预期。
越权修改会被服务端拒绝。共享角色密码下，修改记录中的操作人记到角色级别（如"业务"）。

──────────────────────────────
启动方式（与正式版一致）
──────────────────────────────
双击 start.bat（推荐），或：python run_server.py
服务地址：http://127.0.0.1:5000（局域网访问用本机 IP）

注意：本目录为临时 demo，未合入正式版本；确认交互后由 YYF 合入并发布正式版。
