# 测试能力成熟度 V2.0.27 操作说明

适用环境：Windows，已安装 CPython 3.10–3.13，并勾选 Add Python to PATH。

本包是按 5001（V2.0.26d3）变更准备的下一正式版。**先落到独立目录，不要启动，不要切 5000。**

请复制到 `E:\raft\V2.0.27\`。不要覆盖 `E:\raft\V2.0.26\`。

1. 进入 `V2.0.27` 目录。
2. 把当时 5000 正在用的 `maturity.db` 拷进 `data\`。
3. 等明确说「切」后再双击 `start.bat`（会停旧 5000、启本目录）。
4. 健康检查：<http://127.0.0.1:5000/api/health> 应返回 `"version": "V2.0.27"`。

回滚：`E:\raft\V2.0.26\start.bat`。
