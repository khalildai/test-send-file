# 测试能力成熟度 V2.0.24 操作说明

适用环境：Windows，已安装 CPython 3.10–3.13，并勾选 Add Python to PATH。本包为完整可运行服务版，需启动服务（不是双击 HTML）。

## 1. 解压与目录

请解压/复制到独立目录，例如 `E:\raft\V2.0.24\`。  
**不要覆盖、不要改动** 已有的 `E:\raft\V2.0.23\`。V2.0.23 是回滚基线。
升级时请保留现有业务库 `data\maturity.db`（沿用 V2.0.23），不要用包内初始库替换。

## 2. 首次启动

1. 进入 `V2.0.24` 目录。
2. 双击 `start.bat`。首次会创建隔离环境，并从包内 `packages` 离线安装依赖，不需要上网。
3. 启动失败时窗口会保持打开，同目录生成 `startup.log`。

## 3. 日常启动与访问

- 日常启动：双击 `start.bat`，保持窗口开启。
- 本机访问：<http://127.0.0.1:5000>
- 健康检查：<http://127.0.0.1:5000/api/health> 应返回 `"version": "V2.0.24"`。

## 4. 达成情况页

- 整页下滚时，顶部「新建行 / 编辑选中项 / 删除行」等按钮仍可点击。
- 选中行颜色加深。
- 管理员或能力 Owner 可双击能力信息（领域、Owner、维度、细分能力、描述）打开「编辑选中项」；原来的选中行再点按钮仍然可用。业务方无此双击。
- 编辑选中项保存时会同步该能力组全部科组行，页面立刻显示新内容。

## 5. 修改记录

- 左侧「修改记录」打开独立页面。表格含「来源」列：页面里改的显示「页面修改」；能力台账或组织关系导入 Excel 后保存的显示「导入 Excel」。旧记录没有来源的按「页面修改」显示。
- 该页不再反复整页刷新。每 5 分钟静默拉库时只更新表格内容。
- 默认列宽按文字完整显示；表头可拖列宽。

## 6. 回滚到 V2.0.23

不要删除或改 V2.0.23 目录。若 V2.0.24 有问题，直接启动原来的 `E:\raft\V2.0.23\start.bat`。
