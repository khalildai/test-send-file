# 测试能力成熟度 V2.0.26 操作说明

适用环境：Windows，已安装 CPython 3.10–3.13，并勾选 Add Python to PATH。本包为完整可运行服务版，需启动服务（不是双击 HTML）。

## 1. 解压与目录

请解压/复制到独立目录，例如 `E:\raft\V2.0.26\`。  
**不要覆盖、不要改动** 已有的 `E:\raft\V2.0.25\`。V2.0.25 是回滚基线。
升级时请保留现有业务库 `data\maturity.db`（沿用 V2.0.25），不要用包内初始库替换。

## 2. 首次启动

1. 进入 `V2.0.26` 目录。
2. 双击 `start.bat`。首次会创建隔离环境，并从包内 `packages` 离线安装依赖，不需要上网。
3. 启动失败时窗口会保持打开，同目录生成 `startup.log`。

## 3. 日常启动与访问

- 日常启动：双击 `start.bat`，保持窗口开启。
- 本机访问：<http://127.0.0.1:5000>
- 健康检查：<http://127.0.0.1:5000/api/health> 应返回 `"version": "V2.0.26"`。

## 4. 科组关联

- 能力按科组 ID 挂接，不按名称存归属；页面只显示科组名称。
- 服务启动和保存时把科组 ID 写进库。
- 修改科组名称不会丢掉达成数据。
- 删除科组后 ID 仍保留，新建科组不会复用旧 ID。

## 5. 回滚到 V2.0.25

切到 V2.0.26 前先备份当前运行库。不要删除或改 V2.0.25 目录。若 V2.0.26 有问题，直接启动原来的 `E:\raft\V2.0.25\start.bat`。
